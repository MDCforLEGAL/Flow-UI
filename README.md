# MDC UI (Flow-UI)

Modern, minimalist dark theme UI mod for Geometry Dash using Geode SDK.

## Features
- Siyah-beyaz minimalist dark tema
- Flow leveli temalı akıcı salınım, parlama ve pulse efektleri
- Rüzgar ve çizgisel partikül efektleri
- Modern klik ses efektleri
- Tam özelleştirilebilir ayarlar (Geode Settings API)

## Build
GitHub Actions otomatik olarak Android (32/64), Windows, macOS ve iOS için derler.  
Tag (v1.0.0 gibi) atıldığında otomatik Release oluşturulur.

## Install
Geode mod yükleyicisi üzerinden veya Releases bölümünden .geode dosyasını indirip kurun.
